## [1.0.0] — 2026-05-XX (Play Store v1)

### Added

- Classic endless mode on 8×8 grid with 3-piece tray
- Drag-and-drop placement with ghost preview
- Row/column clears with neon VFX, haptics, and procedural SFX
- Local high score and mid-game save/resume
- Home, settings, game over flows (Expo Router)
- AdMob: banner, capped interstitial, rewarded continue
- Remove Ads in-app purchase (`blockrush_remove_ads`)
- Firebase Analytics (core funnel events)

### Technical

- Expo SDK 56, React Native 0.85, Hermes
- Pure TypeScript engine with 80+ unit tests
- EAS Build profiles: development, preview (APK), production (AAB)
