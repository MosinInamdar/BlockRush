# Store assets — BlockRush

Graphics for Google Play. Not committed as final art — capture from a **production or preview build** on a real device.

---

## Required sizes

| File | Dimensions | Format |
|---|---|---|
| Hi-res icon | 512×512 | 32-bit PNG |
| Feature graphic | 1024×500 | JPG or PNG |
| Phone screenshots | 2–8, min 320px short side | PNG or JPG |

---

## Suggested screenshots (4–6)

1. **Home** — logo, best score, Play button  
2. **Gameplay** — grid mid-game, score visible  
3. **Clear** — line clear / combo moment (screen record frame)  
4. **Game over** — score + Watch to Continue  
5. **Settings** — SFX toggle, Remove Ads (optional)

Use dark background; avoid status bar clutter (enable immersive mode or crop).

---

## Feature graphic tips

- Background: `#0D0D14`
- Title: **BlockRush** in electric blue `#00D4FF`
- Subtitle: *Neon Block Puzzle*
- Optional: 3 glowing block shapes from brand palette ([CONTENT-SPEC.md](../docs/CONTENT-SPEC.md))

---

## Export icon 512×512

From design tool or upscale `assets/icon.png` before final art is ready. Play requires **no rounded corners** in the file (Play applies mask).

---

## After export

Upload in Play Console → **Main store listing** → Graphics.
